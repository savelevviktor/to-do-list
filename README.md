# To-Do List на чистом JavaScript

Одностраничное приложение: регистрация/вход/выход, сохранение сессии, задачи (добавление, выполнение, удаление, редактирование по двойному клику), фильтры, поиск с подсветкой, тёмная тема, адаптивная вёрстка. Данные хранятся в `localStorage` (задачи — отдельно для каждого пользователя).

## Запуск
Используются ES-модули, поэтому нужен локальный сервер (не `file://`):

```bash
cd todo-app
python -m http.server 8000   # затем открыть http://localhost:8000
```

## Структура
- `js/storage` — обёртка над localStorage
- `js/auth` — `AuthService` (логика, хеш пароля SHA-256 + соль, сессия) и `AuthUI` (формы, валидация)
- `js/tasks` — `TaskService` (хранение), `TaskManager` (логика, фильтр/поиск, Observer), `TaskRenderer` (DOM)
- `js/utils` — хелперы и валидаторы
- `js/app.js` — точка входа, делегирование событий

> Хеширование пароля на клиенте — только в учебных целях; настоящую авторизацию делают на сервере.
